# Как отслеживать ежедневные привычки в Habit Tracker

## 1. Предусловия

Перед началом работы необходимо:

- Скачать проект Habit Tracker с GitHub.
- Распаковать файлы проекта в отдельную папку.
- Установить современный браузер (Google Chrome, Microsoft Edge или Firefox).
- Убедиться, что JavaScript включён в браузере.

## 2. Шаги

### 1. Открытие приложения

Откройте файл `index.html` в браузере.

### 2. Начало работы

Нажмите кнопку «Get Started».

### 3. Создание аккаунта

Введите имя, адрес электронной почты и пароль в регистрационной форме.

### 4. Вход в приложение

Войдите в систему, используя зарегистрированные электронную почту и пароль.

### 5. Переход к привычкам

Выберите раздел «Habits» в навигационном меню.

### 6. Добавление привычки

Нажмите кнопку «Add Habit».

### 7. Настройка привычки

Введите название привычки, категорию, периодичность и ежедневную цель.

### 8. Сохранение привычки

Нажмите кнопку «Save».

### 9. Отметка выполнения

Нажмите кнопку отметки выполнения рядом с нужной привычкой.

### 10. Просмотр прогресса

Откройте раздел «Progress».

### 11. Просмотр достижений

Выберите раздел «Achievements» в навигационном меню.

### 12. Создание цели

Откройте раздел «Goals» и нажмите кнопку добавления новой цели.


## 3. Ожидаемый результат

Пользователь успешно создаёт аккаунт, добавляет личные привычки, отмечает их ежедневное выполнение, устанавливает цели и просматривает статистику прогресса и достижения.

Данные приложения сохраняются в локальном хранилище браузера (LocalStorage).
